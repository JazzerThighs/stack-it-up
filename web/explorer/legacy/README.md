# Preserved AnimCubeJS implementation

`../AnimCube3.js` is the unchanged third-party renderer. `animcube-explorer.js`
is the pre-migration explorer including AnimCube setup, identity tracking and
Three.js jelly implementation. These files are reference material, not loaded
by the application. The measured ANIMCUBE_CUBIE_MAP and toFacelets generation
remain in the active explorer, and the Facelet data panel remains available.
