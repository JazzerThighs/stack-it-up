Camera & style
Lighting

Light follows the camera. Shared with the game.

Lighting by element

Model default uses positional light for Gameboy, surface light otherwise. Unlit guides stay unlit.

Piece assembly

Tetracubes are complete, valid groups of four. Fragments belong to incomplete or excluded groups; extra cubies stay cubes. Explorer detection follows the packing filters. Keep Cut Pieces preserves original surfaces through cuts and moves; stack colors still follow the game.

Cube sizes

100% uses automatic fit. Active Pieces also sizes the combined game cube; Stack sizes the separate stack view. Larger sizes may crop corners.

Interface theme

Shared by both apps. Piece colors are unchanged.

Jelly shaping

Smooth beveled ring with a rounded-square opening. Cosmetic only.

Higher: bevels start closer to the face centers.

Low: nearly straight chamfer. Middle: rounded. High: near-square corner. Width stays independent.

Lower values keep inside corners sharper. Angular models use flat faces and straight bevels; width and O-ring controls apply.

Opening size when rounded-square O rings are enabled.

Dither tuning

Pixel size controls resolution. Fewer levels give bolder shading.

ASCII tuning

Lower edge coverage keeps more characters. Blending softens movement.
